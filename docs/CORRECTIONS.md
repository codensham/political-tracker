# Corrections

Found an error? Open an issue, or open a pull request that fixes the record.

- Name the record id and the source you checked.
- Correct the record's source fields in place. There is no corrections field (D-013): the record shows the current value, and git keeps the history.
- In the pull request description, state the prior value and the corrected value, so the change is visible to reviewers.
- A quote correction must match the linked source word for word. CI re-checks the quote.
- If a record is wrong and has no valid source, delete it through a pull request, and state why in the description.
